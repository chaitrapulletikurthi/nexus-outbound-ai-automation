# Phone number: Telnyx or Twilio?

**Vapi powers the voice conversation; a telephony provider connects it to the phone network.** You generally pay for both AI usage and telephone minutes/number rental.

| Consideration | Telnyx | Twilio |
|---|---|---|
| Outbound number | Purchase/import supported number | Purchase/import supported number |
| Setup | Account funding, outbound voice and number configuration | Account funding, outbound voice, voice permissions and number configuration |
| Vapi link | Import a Telnyx number and test call routing | Import a Twilio number and test call routing |
| Trial limitations | Confirm trial calling restrictions and verification | Confirm trial restrictions, verified destinations and account permissions |
| Troubleshooting | Check Telnyx connection/call logs | Check Twilio call logs and error codes |
| Costs | Number + outbound usage + Vapi/AI usage | Number + outbound usage + Vapi/AI usage |

**Before choosing:** check regional support, caller ID registration and reputation, inbound callback handling, number portability, billing/capacity, business verification and current rate cards. Do not estimate costs using an old free-tier price as a guaranteed rate.

Sources: [Vapi Telnyx](https://docs.vapi.ai/telnyx), [Vapi Twilio](https://docs.vapi.ai/phone-numbers/import-twilio/), [Vapi outbound](https://docs.vapi.ai/calls/outbound-calling).
